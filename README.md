# DonkeyKong

This code is based off the solution code for A1.

Credit to the OOSD course for the skeleton code.
Assignment 2 implementation was built off the work,
and continues some of the design choices.

Controls:
Left/Right arrows - Left/Right
Up/Down arrows - Up/Down ladders
Space - Jump
S - shoot

Aim:
Defeat donkeykong with 1 hit of the hammer or 3 shots of the gun.
Collect points by jumping over barrels, destroying barrels, or hitting monkeys.
